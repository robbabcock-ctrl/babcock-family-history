# Potential Enhancements

Ideas for improving how this archive is shared and organized. Not scheduled; revisit when ready.

## Family-friendly website (GitHub Pages)

*Added 2026-09-28*

The repo is public, so anyone can already browse it with no login. But GitHub's file browser is
clunky for non-technical relatives. Turn on GitHub Pages and build a simple site at
`https://robbabcock-ctrl.github.io/babcock-family-history/`:

- Home page with a short intro and links to each family line
- Photo galleries (Bernie Scrapbook, Aunt Sandi photos, research images) with captions
- The narrative papers (*From Westerly*, *The Girl from the Poorhouse*, etc.) as downloadable PDFs
- Family charts (`james-to-sandi`, `solomon-to-sandi`) embedded
- No login required: one link to hand out to family and fellow researchers

## Storage headroom for large photo sets

*Added 2026-09-28*

The repo is about 790 MB. GitHub recommends keeping repos under about 1 GB, blocks single files
over 100 MB, and warns at 50 MB. Before the next big photo drop, decide between Git LFS and a
public Google Drive or Google Photos album linked from the site.

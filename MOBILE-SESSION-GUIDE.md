# If you're a Claude session reading this from Robert's phone

This repo is the permanent archive for Robert Babcock's family history research. Most of the
work happens in a separate **Claude Code session on Robert's desktop**, which has full read/write
access to this repo and a persistent memory of the whole project. If you're a Claude mobile app
session that Robert has pointed at this public repo, you can **read** everything here, but you
have no way to commit changes back — so please don't try to edit files directly, and don't tell
Robert a change is saved unless he's the one who pushed it.

## Get oriented fast

- Start with **`README.md`** for a map of what's in this repo.
- **`Research Log - Master Notes.md`** is the canonical record of everything already known —
  check it (Ctrl+F for a surname or person) before doing research that might duplicate work
  already done. It's organized by family line, then an Outstanding Tasks checklist, then the
  full chronological session history.
- Sourcing convention: facts are marked **CONFIRMED** (primary source or direct family
  confirmation) or **UNCONFIRMED** (memory, single source, or hypothesis). Keep that distinction
  if you report new findings — don't let a guess get stated as settled fact.

## How to hand off what you find

The desktop session can't see this conversation and won't know anything happened here unless
you tell it. The working process (confirmed with Robert 2026-10-03):

1. **Email Robert at rob.babcock@gmail.com** with anything worth preserving — a new document
   you found, a reply from a family member, a research lead, a drafted message he should review.
2. **Start the subject line with `[Mobile Research]`** so it's easy to find and search for.
3. Include enough detail in the email body that the desktop session doesn't have to guess —
   full text of what you found, the source/URL, and why it matters. Treat it like a message to
   a colleague who wasn't in the conversation, because that's exactly what it is.
4. The desktop session checks for `[Mobile Research]` emails when Robert is active in that
   session, verifies/expands on what you found, writes it into `Research Log - Master Notes.md`
   with a proper citation, and commits and pushes it — the same process used for every other
   source in this project. You don't need to (and can't) do that part yourself.

Don't guess at what's already in the tree or the log from memory of a past conversation — this
repo is the source of truth, and it changes often. When in doubt, check it fresh.
